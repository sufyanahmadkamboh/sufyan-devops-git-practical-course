# Module 23 · Real projects

> Level 24 · six projects, from your first repository to a deployed DevOps repository

Lessons teach one thing at a time; projects combine them. Each project has a brief, requirements, a starting point,
hints, a reference solution (hidden until you open it) and a **self-check** script that tells you, line by line,
whether your result meets the requirements.

| # | Project | Level | Practises | Time |
|---|---|---|---|---|
| 1 | [Personal Git repository](project-1-personal-repository.md) | beginner | init, commits, `.gitignore`, branch + merge, tag, remote | 60 min |
| 2 | [Team collaboration](project-2-team-collaboration.md) | intermediate | three developers, protected `main`, PR-style merges, review changes | 90 min |
| 3 | [Conflict resolution](project-3-conflict-resolution.md) | intermediate | content, modify/delete and append conflicts; rebase conflicts | 60 min |
| 4 | [Git recovery](project-4-git-recovery.md) | advanced | deleted branch, hard reset, detached commit, dropped stash | 60 min |
| 5 | [Release management](project-5-release-management.md) | advanced | semantic versions, annotated tags, release branch, backport, changelog | 90 min |
| 6 | [DevOps repository](project-6-devops-repository.md) | advanced | Git tags → Docker image → kind → Helm deploy, rollback | 2 h |

Run each from the course folder; every project creates its own lab under `~/git-practice/` and removes it at the end.
