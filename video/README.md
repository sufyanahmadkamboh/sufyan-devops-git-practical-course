# Video series

> The YouTube upload package (`youtube/`) is written by the build and kept locally; it is not published in this repository.

The course as **23 videos**: one per module (01–20), plus the DevOps workflow, the 18 troubleshooting problems and the
capstone. Each lesson is played as a conversation between a **senior DevOps engineer** and a **junior colleague**
(two voices): the junior asks, the senior explains with the lesson's diagram, they run the lesson's commands, the
junior makes the lesson's mistake on purpose, they read the error together, fix it, and recap.

**Every terminal shows real output.** The commands and outputs on screen are the lessons' tested blocks: the outputs
recorded by `tests/run.sh --update` when the lessons ran (with Git 2.54, and against GitHub for the GitHub modules).
The diagrams are the lessons' own. Nothing on screen is typed by hand, and the narration is the lessons' text.

## Two versions of every video

| File (in `out/partNN/`) | Picture | Sound |
|---|---|---|
| `git-course-NN-<topic>-full.mp4` | the edited video, 1920×1080 | narration (two voices), original background music ducked under the voice, subtle sound effects; -14 LUFS |
| `git-course-NN-<topic>-silent.mp4` | **the identical picture stream** (copied from the same encode with `-c:v copy`: same cuts, transitions, animations, frame for frame) | none (no audio track) |

Production touches, each with a purpose: an animated title card and end card per video, lesson chapters and a
progress bar, a speaker badge (senior / junior), elements that ease in as they are explained, terminals that follow
the newest lines, short fades between scenes, a whoosh on each cut (stronger on a new lesson), an error tone when the
junior's mistake breaks something and a chime when the fix is verified.

All music and sound effects are original and generated by code. [AUDIO-LICENSES.md](AUDIO-LICENSES.md) lists every
audio asset of every video with its creator, source, license, attribution, and the timestamps where it plays (written
from the real timelines).

## Upload packages

`youtube/partNN/` holds, per video: `title.txt`, `description.md` (with chapters), `chapters.txt`, `captions.srt`
and `thumbnail.png` (1280×720).

## Files

| File | What it is |
|---|---|
| `series.py` | turns the lessons into scenes: concept, demonstration, break it, fix, recap; the two speakers; speech clean-up |
| `production.py` | title card, end card, speaker badge styles |
| `components.py` | building blocks: cards, checklists, code panels, terminals |
| `build.py` | page → frames (with ease-in frames) → narration → encode → captions, chapters, description → post-production |
| `audio_assets.py` | the original music bed and sound effects (synthesised) |
| `redact.py` | removes identifying data from everything that reaches a video; the build fails if any remains |
| `shot.mjs`, `tts.ps1`, `thumbnail.html` | frame screenshots with headless Edge; narration with the Windows speech engine; thumbnail |

## Build

Requirements: Windows (for `System.Speech`), Python 3 with `pygments`, `numpy` and `scipy`, Node.js 22+, Microsoft Edge
(or set `BROWSER`), and Docker (ffmpeg runs in a container pinned by digest).

```text
python video/series.py                 the series: scenes and estimated length per video
python video/build.py 8                one video (module 08), all steps
python video/build.py all              every video, then AUDIO-LICENSES.md
```
